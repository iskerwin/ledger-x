# Ledger X 全量审查记录（2026-10-23，1.0.3 开发中 / main 52cf772）

这是一次性的审查记录，不是开发规则；规则以 [开发手册](../development/README.md) 为准。外部审查给出一份 88 条的合并报告（安全与实现 bug、交互与 UI 统一、文案本地化无障碍、动效与 UI 建议、项目级建议、里程碑庆祝方案），本文记录逐条核实的结论、Kerwin 的决定和排期。原报告不入库；文案、本地化与无障碍一篇另见 [盘点原文](copy-i18n-a11y-audit.md) 与 [核实](2026-10-23-文案本地化无障碍核实.md)。

安全类条目在修复发布前只写问题类别，不写细节。

## 结论

- 第一篇 P1 共 15 条（安全 8、LedgerKit 实现 7），对照 main 逐条核实**全部属实**；其中「自建服务器未强制 https」实际影响较小：App 没有 ATS 例外，公网明文 http 本来就会被系统拦下，只有局域网地址能走 http。
- 报告有误或与仓库规则冲突的三处：
  - 「余额断言容差应改为半位」：Beancount `ops/balance.py` 对 balance 明确取两倍容差（allow twice the multiplier），App 现状一致，不改。
  - 「加 GitHub Actions CI」：与 AGENTS.md 和 `tools/check_project.py`（验证只在本机 `ship.py`）冲突，不做。
  - 「显式 withAnimation 不受根节点减少动态效果影响」：不准确，根节点 `.transaction` 会改写其下的显式动画；只有 sheet 等独立呈现层不在其下。
- 已过时（1.0.3 已做）：数字滚动过渡、动效令牌 AppMotion、symbolEffect、设置的「外观」二级页、两处保存触感不同（有意区分保存成功与暂存本机）。
- 不适用：App Store 评分请求（App 不上架，侧载安装无效）。

## Kerwin 的决定

- 1.0.3 先转正式版；正确性与安全修复放 1.0.4；图表、UI 统一、动效放 1.0.5。
- 自建服务器地址保留 http，但连接页警告；快捷指令在 App 锁开启时不直接读写（查询提示先解锁，快速记账转草稿待确认）；开启 App 锁时提示本机账本在「文件」中可见。
- WebDAV 服务器是否支持防覆盖无法逐一确认：不拦写入，改为检测并在同步页提示。
- 汇率早于首个价格点时的换算方式不改（不接受报表出现「未换算」提示）。
- 大号金额随系统字号放大；未使用的 `ActionGroup` 与间距令牌删除；弹层统一三档；数字键盘按下只变色；空状态按钮加在预算、往来、事件、订阅；预算页中文名为主、超支说明原因。
- 术语：「商户」改「收付款方」；交易说明统一叫「摘要」。
- 搜索统一用明细页那种：常驻导航栏下方，下翻时悬浮为液态玻璃。
- LICENSE 以后再定。
