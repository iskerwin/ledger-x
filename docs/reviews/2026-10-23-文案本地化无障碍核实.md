## 核对后不改

- **「管理账户 / 科目管理」**（AccountManagerView:33）：不是同页矛盾。同一视图有两种打开方式：账户页进入显示全部账户，叫「管理账户」；记一笔宫格进入只显示支出或收入科目，叫「科目管理」。符合盘点自己提的「账本面用科目」分工。
- **「无支出记录」与「暂无支出记录」**（OverviewView）：前者用在上月或去年同期（已经过去），后者用在当前周期（还可能有），语义不同。
- **EntryActions「仅删除这一条记录」**：这是非交易条目（余额断言等）的删除确认，用「记录」正确。
- **en.json 加载失败静默回退中文**（Lang.swift）：现在 `check_project.py` 每次都解析并核对 en.json，坏文件进不了发布，不再另加日志。

## 待 Kerwin 确认（会改变用户看到的名称或范围较大）

1. **术语改名与口径成文**：payee 的「商户」改为「收付款方」（约 23 处，含概览「商户支出排行」、设置「商户拼音」；写进设置文件的键名不改）；narration 的「摘要」改为「备注」（7 处）；把「收付款方 / 备注 / 交易与记录 / 操作面分类、账本面科目」写进开发手册。改名需同步指南与 CHANGELOG。
2. **筛选空状态三种说法**（「没有符合筛选的交易」「没有符合筛选的记录」「没有符合条件的交易」）与**错误、同步状态的双说法**（「无法 X」与「X 失败」、「同步中…」与「正在同步」、「同步出错」与「同步没有完成」）：建议先定口径再定点改。
3. **A3 图表朗读**：概览趋势、报表、预测、持仓、月历收支条的图表没有数据描述，VoiceOver 用户拿不到这些数据；Donut 图例可作模板。建议优先于观感类条目。
4. **A4 手势等价**：带左滑动作的页面里，多数没有长按菜单或 VoiceOver 自定义动作。
5. **A5 `ActionGroup` 无人使用**：已核实全仓 0 处引用。用起来或删除，需定方向。概览月份条在大字号下标题会折行的问题，已在 1.0.3 用单行加缩小处理（SlidingTitle）。
6. **A6 大号金额固定字号**：34 / 40pt 不随动态字体变化；同类的数字缩小兜底在概览摘要卡已改为换行（e14a985），其余卡片未动。
