### 1.1 四组同物异名

### 1.2 指南漂移（GuideView，51 个引用名逐个核对）

- **D1FAQ 第一条**让用户去「设置 → 同步队列」点「立即同步」——这两个名字界面都不存在：设置行实际叫「同步与最近改动」（SettingsView:63），同步页按钮是「推送」（SyncView:67）。指南正文还有一处同类问题：写「设置 → 顶部的账本卡片（账本同步）」，把到达页标题当成了设置行名，用户按图索骥会扑空。
- **D2 附件恢复 FAQ** 的命名链含混：「已同步记录」（同步页分区）与「撤回」（历史页「最近改动」）被链在一起，建议指南统一按设置行名起笔；跳转关系需真机确认。
- **D3 订阅 FAQ** 把界面上两个并列按钮「记一笔扣费」「记一笔续费」（SubscriptionView:652）压缩写成「记一笔扣费 / 续费」，按字面找不到第二个。
- **D4 指南内部简称不一**：报表主题与界面都叫「试算平衡表」，FAQ 里写成「试算表」。
- 其余 40+ 个引用名（含「使用设备密码解锁」这类格式串渲染结果）逐条核对无漂移。

### 1.3 动词与句式

- 保存（落盘）29 / 完成（收键盘关弹层）30 / 取消 47：分工已成套路。同动作两名一处：「保存再记」（卡片）vs「保存后再记一笔」（完整表单 AddView:841），建议统一前者。
- 删除（删实体）/ 移除（从列表队列拿掉）/ 清除（清缓存）三分工基本成立；跨页异名一处：同一件「把暂存改动拿掉」，同步页叫「移除」（SyncView:68/164）、检查页叫「删除」（ChangeReview:105），以「移除」为准。
- 空状态三语境已有主流说法（列表空「还没有 X」、搜索空「没有找到 X」），但筛选空有三个版本并行（「没有符合筛选的交易 / 的记录」「没有符合条件的交易」），且 OverviewView 同页「无支出记录」与「暂无支出记录」并存。
- 错误句式两家族并行（「无法 X：%@」28 处 / 「X 失败：%@」13 处），语义本有别（不允许 vs 试过没成），缺的是成文口径。同步状态有两对双说法：「同步中… / 正在同步」、「同步出错 / 同步没有完成」，同状态跨页说法不同，建议各留一个。

## 二、本地化

### 2.1 机制是健康的

LS 查表链完整：全键查表 → 「：」前缀回退（给账本整段消息用）→ 中文原文回退，所以缺译只会「英文界面漏中文」，不崩溃不空白。2108 个键逐条比对，键与译文的 `%@` 占位符数量不一致 **0 条**；没有把变量拼进键的写法；语言切换无 @State 固化文案残留。界面主通道纪律满分（未走 LS 的中文 Text/Label 为 0 处，本轮又逐通道核查了标题、按钮、Picker、占位符、通知、Toast，均无写死中文）。

两个机制层小缺口：en.json 加载失败时静默全量回退中文、无日志（Lang.swift:36-41），真出问题无从定位；日期/金额格式键靠译文逐条适配（如键 `%@ 年` 的译文就是 `%@`），每新增格式键都要人工记得补译——本轮缺译正是这么漏的。

### 2.3 未引用 64 条：16 条勿删、48 条可删

- **动态已覆盖 16 条（不要删）**：持仓区间 `1月/3月/6月/1年/5年`（常量表经 `LS($0.2)` 查表）、`下次扣费/下次续费 %@（%@）`（三元双键）、附件格式说明 1 条、内置查询名 8 条（LedgerKit 定义、经 `LS(name)` 查表）。
- **死译文 48 条（可删）**：成因高度一致——改版把短句/片段升级成整句键，旧译文无人删。三组：被整句键取代的旧片段 22 条（如 `删除 %@` → 现行 `删除 %@ %@？`；两条「文件已经变了…」旧版 → 现行合并键）、改名/标点差异旧键 5 条（如 `填写对方` → 现行 `填写对方…`）、功能删除后无引用 21 条（如 `实扣合计`、`转账金额`、`近两个月没有扣费`，全仓无此串）。逐条清单与每条的现行键证据在 audit-i18n.md 第二节。其中 4 条是缺译键的配对孤儿，**先补译、后删除**，顺序别反。

### 2.4 两个整通道绕过 LS（恒中文，单独立项）

- **App Intents 静态元数据**：4+1 个 Intent 的标题/描述、参数标题 9 处、快捷指令短标题 4 处、Siri 唤醒短语 6 条都不经 LS 且无.strings 承接——英文用户在快捷指令/聚焦里看到全是中文，英文短语唤不醒 Siri（Intent 的运行结果对话本身走 LS，没问题）。
- **系统权限弹窗**：project.yml:40-42 三条 UsageDescription（面容/相机/相册）仅中文；全仓 0 个.strings/.lproj，bundle 级本地化完全缺位，App 内语言设置管不到。
- 低风险一项：Swift Charts 维度名约 33 处写死中文（`金额/月份/类别`等），是内部标识、系列值已 LS，仅图表无障碍描述可能带出，优先级低。
