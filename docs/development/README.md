# Ledger X 开发手册

本手册定义 Ledger X 的功能、数据规则、架构、本机测试与发布、测试样本与手机验收；协作约定见 [AGENTS.md](../../AGENTS.md)。时间统一使用北京时间（UTC+8）。

首次接手阅读顺序：00 → 02 → 03 → 04 → 01 → 05 → 06。

| 分篇 | 内容 | 何时修改 |
| --- | --- | --- |
| [00 项目概况](00-项目概况.md) | 定位、仓库与数据边界、工程约定 | 很少；边界变化需 Kerwin 决定 |
| [01 产品功能与交互](01-产品功能与交互.md) | 功能清单、交互与限制 | 功能、入口或交互变化时 |
| [02 记账与数据规范](02-记账与数据规范.md) | 文本、金额、汇率、分录、文件与数据安全 | 规则变化时（先确认） |
| [03 技术架构与代码导航](03-技术架构与代码导航.md) | 目录、调用链、状态与修改入口 | 模块或数据流变化时 |
| [04 本机测试与发布](04-本机测试与发布.md) | 环境、ship.py、开发版与正式版、IPA 源 | 测试或发布流程变化时 |
