# 01 产品功能与交互

本篇定义 Ledger X 的功能与交互要求，手机验收步骤见 06。新增或改变行为按 [AGENTS.md](../../AGENTS.md) 先明确方案与授权。安装包怎么发出去（相关测试 → 开发版 → 手机验收 → 同一源码全量 → 正式版，以及合并前的 PR 检查）见 [04](04-云端测试与发布.md)，不在本篇改界面行为。

## 导航、入口与术语

iPhone 主导航为概览、明细、记一笔、账户、报表；记一笔是在当前页面打开的卡片，iPad/宽窗口使用侧栏。未连接时可选择演示账本、本机新建空账本或连接存储。设置中管理多账本。

| 名称 | 含义 |
| --- | --- |
| 快捷记账 | 分类宫格、账户、金额计算器和常用交易 |
| 完整表单 | 更多→完整表单，与快捷记账共用草稿 |
| 分录（多行） | 多条账户金额分录的录入模式 |
| 文本（Beancount 指令） | 可录入多条指令的模式 |
| 编辑源文本 | 当前交易生成文本或已有原文的编辑，与文本模式区分 |
| 收付款方 | 交易 payee，界面一律叫「收付款方」（搜索仍认 `商户:`；报销单导出的表头和账单导入的列名按外部习惯叫「商户」）；交易的说明文字（narration）一律叫「摘要」（搜索 `摘要:`、`备注:` 都认），账户上的 note 指令叫「备注」 |
| 分类 / 科目 | 同一个 Beancount account 的两种叫法：选择、筛选、改类这类操作界面叫「分类」；搜索语法、科目管理、报表这类账本界面叫「科目」 |
| 交易 / 记录 | 一笔账叫「交易」；「记录」只指扣费、变更、同步、余额断言等事件或非交易条目 |
| 删除 / 移除 / 清除 | 删除：从账本删掉条目或实体；移除：从列表或队列拿掉（暂存改动、附件引用）；清除：清空缓存或输入 |
| 保存 / 完成 / 取消 | 保存：写入账本或设置；完成：收起键盘、关闭不写入的弹层；取消：放弃本次修改 |
| 币种与汇率 | 录入金额、银行报价与手续费；浏览时的“币种与换算”另算 |

## 记账与无损编辑

支持支出、收入、转账、跨币种换汇、退款（可选同时退回同币种银行手续费）、AA、报销垫付、组合付款/优惠、备用金、多分录和文本。快捷记账的转账用两张账户卡片表示转出与转入（图标、名称、尾号、余额或欠款，输入金额后显示转账后余额，跨币种显示到账币种，同账户换汇时提示），中间圆形按钮对调；手续费不再单独一行，支出和转账都在「币种、汇率与手续费」里填写，填了后金额下显示摘要。选账户（`AccountPicker`，各处共用）打开时从「最近使用」「最常用」开始，已选账户固定在搜索框下、不在列表中重复；转入列表里转出账户标「同账户换汇」。特殊组合受 draftIssue 和往返校验限制，不能宣称任意组合均支持。

- 新建可保存并关闭，或保存后再记；历史交易保存修改，复制生成今天的新交易，不改变原记录。
- 金额支持算式；按商户历史推荐账户/分类，但不覆盖明确的手动选择。
- 未完成内容、标签、链接、商户、说明、金额与分录在可转换模式之间保持；不能无损表示时保留原模式和内容，并提示原因。
- 源文本完成才应用到草稿，取消不改。历史交易只有生成后与原交易完整一致才允许表单编辑，否则保留分录/源文本入口。
- 相同原文的多笔交易按原定位区分，改点开的那笔；无法确认定位时不猜测、不误改另一笔。
- 有未保存修改时，关闭/下滑需明确继续、保留草稿、放弃。草稿按账本隔离，保存期间防连点和关闭。

## 统一交互要求

每个新增或变更面板必须明确进入、填写、取消、关闭、完成/保存、键盘收起和生效时机。账户选择器顶部独立搜索，选中后仍需完成才应用；取消不改变原选择。宫格即时选择与确认式面板不能混写为同一种交互。

输入商户/备注时显示当前字段候选和完成按钮，候选在键盘上方可点；结束输入恢复布局。收起键盘仅隐藏键盘，不保存、不关闭。保存失败保留输入，不能显示成功或提前关闭。

## 多币种、银行报价与费用

币种与汇率统一面板使用局部编辑会话，完成时校验后整体应用，取消或下滑不应用。可选目标币种与报价方向，保持银行原写法；同账户只允许不同币种换汇，同币种同账户拒绝。

换汇费用支持转出内含、转出外另扣、目标到账内扣、其他账户/币种单独支付；显示本金、实扣、费用、净到账，不混加币种。普通支出只使用另付和单独支付，商品与费用分别记录，不把费用当商品本金。科目统一 Expenses:Fee:Bank，缺开户/币种不符须提示。

实际两端金额与银行报价不一致时提示核对，不静默改写银行报价。保存、编辑、复制、模式往返和草稿字段兼容必须独立验证，详细语义见 02。

## 保存、同步与撤回

保存前检查账户、平衡、断言、负余额/额度等。修改安全写入本机队列后，保存并关闭的卡片先关闭，再重建余额并显示一次包含余额的成功提示；普通保存不等待网络推送。保存再记时提示位于当前卡片，不重复叠在根页面。

成功提示在卡片关闭及重建后计时，无撤销约 3 秒、有撤销 6 秒，其他建议排队。撤销在最近改动或提示入口执行，与放弃未保存修改不同。后台同步失败保留队列，可重试；切账本/连接/缓存操作防过期结果串账。系统退出后不承诺后台持续联网。

同步状态同时用图标、文字和颜色区分：正常等待与离线用中性色，需要检查的暂存用橙色，失败用红色，同步中用主题色箭头；导航栏、设置和同步页采用同一套显示规则。现金流预测曲线保持主题色，负余额最低点用红色三角标出；预算正常、进度过快、超支分别用主题色、橙色、红色，超支同时显示斜纹和说明。

## 浏览、账户与业务

明细支持组合查询、快速搜索、日期/月历、筛选、批量编辑和同日顺序。月历用共用 `GlassMonthCalendar` 六行网格：标题、月度数字、星期与日期。箭头、横滑、标题年月滚轮换月，同字号下卡高固定；今天主题色实心圆，正在查看的那天淡色圆。红点支出、绿点收入（同一天两种都有时红左绿右，点在日期下居中），按当月各自最大日金额分三档大小，其他交易为灰点；点一天就打开当天明细，弹层用下拉或完成关闭，日期下面没有当天摘要。一周从哪天开始跟随手机系统日历，星期表头与日期对齐，搜索「本周」「上周」用同一个起始日。非本月补位日与范围外日期不可点。订阅日历用主题色单点，点选立即筛出当天扣费，保留今天至未来 62 天范围与「显示整月」。月历直接排在列表那一张卡片里，不套玻璃，箭头没有玻璃底，网格周围没有内层圆角框或描边，不显示圆点大小提示行。`journal.glassCalendar` 默认开，关闭两处均回退系统月历（保留一个版本）。明细打开月历时，月历占据快捷筛选那一行的位置，快捷筛选、标签和「全部时间」一行收起，已加的条件与「清除」照常显示；收起月历恢复。搜索框输入时不检索，按键盘「搜索」后才应用；清空搜索框、点标签或快速搜索立即生效。报表/账户/预算跳转携带相应条件，可恢复上次筛选。导航栈主要在本次运行内保存，不承诺退出后完整恢复所有页面。

账户包括余额、滚动明细、断言、备注、票据、余额核对、信用卡周期与还款、投资持仓。有需要报价的证券或外币时，账户页显示「更新价格」入口和最新价格日期，不必先进投资持仓。余额核对区分空值、无效输入和差额；信用卡区分手填与估算。个人/公司往来、报销和备用金按实际账户及币种办理，不将不同币种直接相加。

报表包括概览洞察、分类/商户、年度回顾、损益表、资产负债表、试算平衡表、预算、现金流预测、订阅、报销、工资、事件、值得留意与查询。支持 BQL 常用子集及 .bql/query 指令，不宣称完整官方 BQL。

BQL 查询结果以正文色显示并保留原始正负号，不把通用负数判作亏损或支出；收入、贷方、数量等须按查询含义解释。

单项趋势与排行条使用主题色；收支对比保留收入绿、支出红，配合图例、线型或符号。单独展示的各币种净资产小图用主题色，多币种堆叠图保留币种色。分类构成从 8 种固定颜色中按身份分配（按开户先后各占一种，多于 8 个时与用得最少的共用；都避开收入绿、支出红），不随换月、排序或主题变化，新开的分类不会改动已有分类的颜色；收付款方、账户等其他构成在同一张图里按名称分开。主题色为翡翠（默认）、蓝色、靛蓝、紫色、梅、石墨，不提供与收支、提醒同色的红、绿、橙和做文字看不清的黄；账户分组图标同样不用红绿。具体金额与分类以名称、图例和数字为准。普通报表入口随主题，风险入口保留警示色。

订阅新增、调价、暂停、恢复、取消和关联保留历史；订阅详情与交易详情同一结构：顶部居中卡片（名称、金额与周期、状态、累计）、详细信息（分类、付款账户、扣费方式、开始日期）、需要留意、扣费记录（默认最近 5 笔可展开）、关联记录、折叠的历史，底部操作栏放「记一笔扣费 / 续费」「调价或更改」（非活跃时为「恢复订阅」），其余操作在右上角「⋯」。业务表单统一关闭保护、防重复和切账本保护。预算可编辑并跳转月/年对应明细，包含子科目和正确日期边界。

## 导入、票据与系统功能

- CSV/XLSX：选文件→映射→核对/查重→确认入账→结果；本机按账本保存进度，恢复后重新查重，已入账不重选，部分失败保留剩余项。文件选择器允许 .xls 不表示已支持二进制 XLS。
- 附件：拍照/照片/文件→确认位置文件名→上传→关联。确认附件页打开时按当前账本已有文件和其他待处理附件，连同扩展名给出无编号、`_1`、`_2` 的首个可用默认名。手动改名后刷新不覆盖，保存固定当前路径，本任务的恢复记录不误报重名。账户票据与交易附件保存期间暂停表单位置校验，成功后保持保存状态直到关闭，避免将刚写入的文件误报为重名；账户票据保存中不刷新默认名，失败后恢复校验和编辑。上传转圈时可点取消；取消停止后续步骤并保留恢复副本，已经上传的文件不删除；已写入本机队列的关联可在最近改动撤回。保存失败不关闭，在原页显示具体错误，同一路径再次保存继续原任务；改路径会新建任务并保留先前副本。键盘完成/收起只收起键盘。付款方决定 `document` 的账户；交易附件默认存到 `documents/receipts/`，账户票据存到机构文件夹。账户页有统一的「交易附件」列表，不按账户分；账户详情的票据只列对账单。删除附件或票据可选「只移除引用」或「移除并删除文件」；删除文件时本机保留副本 30 天，撤回会恢复文件，其他记录还在用的文件不删；删除后的提示条可「撤销」，账户页「交易附件」底部的「最近删除」可逐个「恢复」，最近改动里对应记录标「可恢复文件 · 剩 N 天」。上传后交易带上的 `^doc-…` 只用于连接附件，交易详情只在「附件」里列出文件，不出现在关联记录、关联交易和链接检查中。失败前保留本机私有恢复副本，重试路径/链接固定；移除本机恢复副本不删除原文件/远端文件。
- 截图记账：本机 Vision 识别，显示需核对内容，由用户确认入账；快捷指令传图和权限的整条真机流程待验收。
- 后端：GitHub、GitLab、Gitea/Forgejo、文件夹与 WebDAV；离线队列和远端冲突需显示结果和重试入口。
- 设置：账本同步、记账偏好、外观、安全和更多；中英文、深色、隐藏金额、Face ID、触感强度、减少动态效果、提醒、快捷指令与文本备份。

## 显示与可访问性

共用图文间距 8 pt、组内操作 12 pt、内容边距 16 pt，辅助 4 pt、分组 24/32 pt。同组胶囊按钮外框 44 pt，日期小胶囊 36 pt，行内小按钮（还款、加入、置顶、恢复等）外框 32 pt、点按范围上下各多 6 pt 共 44 pt，行高不变；主操作填色玉色，其余描边，破坏性操作红色描边。放不下或无障碍 XXL 及以上改纵向满宽，不缩小关键文字。系统 alert/confirmationDialog 保留系统文字动作。底部提示条分三种：失败或被拒绝的前面是红色感叹号并停留更久，做完了的（已入账、已复制、已备份、已应用等）前面是对勾，其他说明不带标记；提示文字完整显示（最多五行），不截在两行。

小屏/大字体时图例可移到下方。隐藏金额同时隐藏图表轴和 VoiceOver 数值，不能只遮住文字。减少动态效果由系统偏好控制，触感开关覆盖各入口。以上均需按 06 实际验收。
