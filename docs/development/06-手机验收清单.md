# 06 手机验收清单

按功能域列出真机体验步骤。源码检查、PR 检查、云端测试通过和安装包发布都不能代替这里的结果；未确认前一律「待手机验收」。公开反馈只写虚构样本或脱敏描述，不上传真实账单截图、账号或交易编号。

验收针对当前开发版安装包。通过后由 Kerwin 执行 `python3 tools/ship.py release --accepted-build N`（`N` 是手机上看到的构建号），在这一版的同一源码上跑完全量，再把同一个安装包发布为正式版（见 04）。版本号和构建号不变。PR 检查和开发版上的相关测试都不能代替这次手机验收。结果按文末模板记录（可建一个 Issue 汇总）；这里只放步骤，不在仓库里填写结果。新增需要手机确认的体验时，在对应功能域追加步骤。

## 安装与准备

- 在 SideStore、AltStore 和 getzeus.app 的 Zeus 中分别添加发布说明列出的开发版 IPA 源，核对 Ledger X 名称、版本、构建号和本次更新说明，尝试安装或更新；三种客户端结果分别记录。
- 安装开发版 IPA 源里的最新版本，记录版本、构建号和源码提交。验收期间不要再执行 `ship.py dev`：release 发布的是验收时 dev 上的那个安装包。
- 核对主屏幕、设置首页、关于页、锁定页、通知权限提示与快捷指令说明统一显示 Ledger X；切换英文再核对。
- 准备两个互不相同的虚构账本，至少包含本币/外币账户、手续费科目、信用卡、报销、备用金、订阅与附件。
- 先保留测试账本备份；测试关闭、断网、重试和退出时核对原记录与新增记录数量。
- 发现问题记录：版本、入口、填写内容、操作顺序、预期/实际和是否可重复；停止在问题路径上继续叠操作，先报告。

## 汇率、复制与保存

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| FX1 | 总转出 80 HKD，内含手续费 0.20 HKD，银行报价 1 HKD = 0.125310 GBP，净到账 10 GBP | 原币扣 80，费用 0.20，买入 `10 GBP @@ 79.80 HKD`，报价原样保留 |

| RF-3 | 转账/换汇四种扣费方式在同页调整金额与报价；检查无效费与复杂支出 | FX1–FX6 的预期同样成立；无效或不支持组合明确提示并保留输入，不丢字段 |
