# 06 手机验收清单

按功能域列出真机体验步骤。源码检查、本机测试通过和安装包发布都不能代替这里的结果；未确认前一律"待手机验收"。公开反馈只写虚构样本或脱敏描述，不上传真实账单截图、账号或交易编号。

验收针对当前开发版安装包；通过后由 Kerwin 执行 `python3 tools/ship.py release` 把同一安装包发布为正式版（见 04）。结果按文末模板记录（可建一个 Issue 汇总）；这里只放步骤，不在仓库里填写结果。新增需要手机确认的体验时，在对应功能域追加步骤。

## 安装与准备

- 在 SideStore、AltStore 和 getzeus.app 的 Zeus 中分别添加发布说明列出的开发版 IPA 源，核对 Ledger X 名称、版本、构建号和本次更新说明，尝试安装或更新；三种客户端结果分别记录。
- 安装开发版 IPA 源里的最新版本，记录版本、构建号和源码提交。验收期间不要再执行 `ship.py dev`：release 发布的是验收时 dev 上的那个安装包。
- 核对主屏幕、设置首页、关于页、锁定页、通知权限提示与快捷指令说明统一显示 Ledger X；切换英文再核对。
- 准备两个互不相同的虚构账本，至少包含本币/外币账户、手续费科目、信用卡、报销、备用金、订阅与附件。
- 先保留测试账本备份；测试关闭、断网、重试和退出时核对原记录与新增记录数量。
- 发现问题记录：版本、入口、填写内容、操作顺序、预期/实际和是否可重复；停止在问题路径上继续叠操作，先报告。

## 汇率、复制与保存

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| FX1 | 总转出 80 HKD，内含手续费 0.20 HKD，银行报价 1 HKD = 0.125310 GBP，净到账 10 GBP | 原币扣 80，费用 0.20，买入 `10 GBP @@ 79.80 HKD`，报价原样保留 |
| FX2 | 转出本金 80 HKD，选择额外扣费 0.20 HKD | 本金 `@@ 80 HKD`，原币实扣 80.20 |
| FX3 | 转出 100 HKD，目标 GBP，净到账 9.80 GBP，目标币种内扣 0.20 GBP | 毛兑换 10 GBP，目标账户扣费 0.20，合计净增 9.80 |
| FX4 | 费用由另一账户或第三种货币单独支付 | 指定账户按指定币种扣费，不混算币种、不改变换汇本金 |
| FX5 | 四种方式各保存、编辑、复制，再切分录/文本/快捷 | 扣费方式、金额、账户和报价一致，无重复费用 |
| FX6 | 输入费用大于等于含费总额、错误币种或不支持币种的账户 | 就地提示，不能生成错误交易 |
| CP1 | 复制支出、收入、普通转账、带费换汇与复杂分录 | 快捷摘要或复杂提示卡可见收付款方和说明，源文本与最终保存一致 |
| ST1 | 记一笔填写金额和分类后点「保存并关闭」 | 卡片完全关掉后才出现成功提示；无「撤销」约 3 秒，有「撤销」6 秒，都能看清。若随后出现订阅建议，要等这条走完才出现 |
| RF-1 | 打开币种与汇率，同时更改金额、币种和费用，分别取消/下滑/完成 | 无重复汇率标题；取消/下滑不应用任何修改，完成一次应用全部；键盘可收起 |
| RF-2 | 普通支出分别填账单币种费、付款币种费和其他账户第三币种费，再保存/编辑/复制/切模式 | 商品本金、费用、合计扣款对应正确，不重复扣费、不猜测第三币种汇率，原分录读回完整 |
| RF-3 | 转账/换汇四种扣费方式在同页调整金额与报价；检查无效费与复杂支出 | FX1–FX6 的预期同样成立；无效或不支持组合明确提示并保留输入，不丢字段 |

| S2-9 | 在记录较多的测试账本里改一笔并保存，再点「撤销」 | 保存过程中界面不整页冻住；撤销后这笔回到修改前。请用虚构账本 |
