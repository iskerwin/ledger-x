# 00 项目概况

## 项目定位

Ledger X 是原生 SwiftUI iOS 记账与查账 App，支持 iOS 17+ 的 iPhone、iPad。App 显示名称统一为 Ledger X，无自建账号或账务服务器，直接读写用户选择的 Beancount 纯文本账本。电脑端编辑器、Fava 与 bean-check 可继续使用。

Ledger X 的首个版本为 1.0.0。功能要求见 01，账本格式见 02，工程与模块划分见 03。新增需求按 [AGENTS.md](../../AGENTS.md) 确认范围后实施。

## 完成标准

用中文说明实际变化、影响和手机验证方法。代码存在、云端测试通过、IPA 可安装、手机验证是四种不同事实；只有最后一项才能确认体验满足要求。

## 仓库与数据边界

| 仓库 | 用途与约束 |
| --- | --- |
| [iskerwin/ledger-x](https://github.com/iskerwin/ledger-x) | 本项目：公开 iOS 源码、测试与开发手册，仅虚构或脱敏数据 |
| iskerwin/ledger | 私人真实账本，永远不能修改，也不为测试读取或复制内容 |
| [iskerwin/ledger-demo](https://github.com/iskerwin/ledger-demo) | 公开虚构演示数据，只读取；修改前须获 Kerwin 单独授权 |

不得在测试、截图、日志、注释和公开文档放真实卡号/尾号、订单、人名、电话、工作单位或真实账单。演示数据本机修改不写回公共仓库。

## 工程与数据约定

- App：SwiftUI；核心：本地 Swift Package LedgerKit；工程：XcodeGen project.yml。
- App target/scheme：Ledger；UI scheme：LedgerInteractionTests；安装包：Ledger.ipa。
- Bundle ID：com.iskerwin.ledger；URL scheme：ledgerx://；共用账本配置：ledger-x.json。这些标识在工程与数据读写中统一使用，改变时必须明确影响并取得授权。
- 界面以中文为键，英文放 Ledger/en.json。
- Token/密码保存在系统 Keychain；本机还有草稿、队列、缓存、恢复副本和偏好，不能把账本文本备份等同于所有本机数据备份。

开发、测试、构建与发布在 GitHub 上执行。合并前有只读的 PR 检查；开发版要先通过相关测试；手机验收后，才在同一源码上做全量并把同一个安装包转成正式版（见 04）。本机只编辑和做轻量检查。通过 IPA 源用 SideStore、AltStore 或 Zeus 自签安装，非 App Store/TestFlight 发布。安装更新前由用户备份账本，并核对未同步内容。
