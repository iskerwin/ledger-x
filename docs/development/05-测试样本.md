# 05 测试样本与标准答案

## 样本目录

- `LedgerKit/Tests/LedgerKitTests/Fixtures/`：解析、记账、报表、业务与故障场景所需的固定虚构账本和预期 JSON。
- `LedgerUITests/Fixtures/`：模拟器交互使用的虚构账本与导入文件。
- [tools/fixtures/manifest.json](../../tools/fixtures/manifest.json)：样本 SHA256 清单和测试、安装包共用的固定演示提交。

不使用私人账本生成测试数据。校验哈希用于发现样本是否被改动，不作为正确性证明。

## 固定预期结果

`expected.json`、`cases.json` 与 `full/`、`errors/`、`realistic/` 等账本组成回归基线。Swift 测试直接读取已提交样本与 JSON。

不能用待测实现的输出直接覆盖标准答案。需要修改样本时，提交说明必须写明场景、独立计算依据和预期差异，同步样本清单，并保持等价或更强的回归覆盖。新增测试应覆盖正常结果、边界、失败和恢复，避免只验证实现调用了某个函数。

## Beancount 独立对照

- `tools/fixtures/check_reports.py`：重新计算并比较 ReportDumpTests 输出，覆盖余额、估值、折算、收支和净资产，绝对误差阈值 0.01。
- `tools/fixtures/money_expected.py`：生成账户余额、持仓与批次的预期结果。
- `tools/fixtures/year_expected.py`：生成年度/月度收支与净资产预期结果。
- `tools/fixtures/plugins_expected.py`：生成已支持插件行为的预期结果。

脚本开头给出参数示例。测试在本机运行（见 [04](04-本机测试与发布.md)）。金额或报表行为改变时，补充独立计算和具体边界测试，不能仅为获得绿灯改写答案。
